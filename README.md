## AcpGen ##
Repository containing generators for Ancient Coder Pack (ACP) data files. Our equivalent of Forge's MCPConfig, NeoForge's NeoForm, and
FabricMC's Yarn and intermediary repos.

## What gets generated? ##
Generated files include:
- TSRG files for mapping obfuscated Minecraft code
- DiffPatch files for decompiler issues
- MCInjector files for fixing access levels and exceptions.

## How to contribute ##
If you want to help contribute, fork and clone this repository and then commit. More detailed explanations for how
to use the functions in this repo will come later, so for now just mess around with the repo and you should be able to figure it out.
Questions are always welcome, of course.
