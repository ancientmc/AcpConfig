# OBFUSCATION MILESTONES
Versions of Minecraft that mark a significant shift in the way Minecraft's code is obfuscated.

## preclassic
All versions of pre-classic are deobfuscated. They also retain additional data like exceptions, generics, and LVT data.

## c0.0.12a_03
First obfuscated version of the game. 

## c0.0.14a_08
Notable for being partly obfuscated. Certain classes are left deobfuscated for serialization purposes.
